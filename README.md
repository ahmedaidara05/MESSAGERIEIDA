# MESSAGERIEIDA

Application de messagerie web (chat) avec Firebase Auth / Firestore et Supabase (stockage).

## Utilisation

Ouvre `index.html` dans un navigateur, ou déploie sur GitHub Pages / Netlify / Vercel.

## Configuration

- Firebase projet : `messagerie-74782`
- Les clés sont dans `index.html` (firebaseConfig)

## Mode Couple

Dans Paramètres d'une conversation, active le **Mode Couple** pour afficher les outils spéciaux (jours ensemble, flamme, cadeaux, etc.).
